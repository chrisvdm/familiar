# Mobile View

The landing page and docs pages need responsive layout work for mobile screens.

## Known Issues

- Landing page sections overflow on narrow viewports
- LiveDemo chat panel is fixed at 400px height and may not adapt to mobile screens
- Navigation may need a hamburger menu or collapsed state
- Docs content sidebar/order may need stacking on mobile
- Input fields and buttons in LiveDemo may be too small for touch targets

## Notes

Test on actual devices or browser dev tools at 375px and 768px breakpoints.
